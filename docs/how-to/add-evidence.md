# Add evidence

Bring a new source into the design, for example a framework from a domain not yet covered.

1. Read the source at its origin. Note its edition, the sections you read, and anything you could not read and why.
2. Add it to [the bibliography](../reference/bibliography.md) under its domain: a short key in capitals, the full citation with a link, and how far it was read, naming the sections, so that every section a record cites can be checked against it.
3. If it changes the argument, paraphrase it in [the evidence](../explanation/the-evidence.md), citing its key. Quote at most one short passage.
4. For each requirement it supports, qualifies or contradicts, cite it in the requirement's **Evidence** and comment on the requirement's review issue. Propose a new requirement, with status `Proposed`, where it reveals a gap.
5. Run `just test` and open a pull request.
