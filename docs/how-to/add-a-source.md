# Add a source

Bring new evidence into the design, for example a framework from a domain the research did not cover.

1. Read the source at its origin. Note the edition, the sections you read and anything you could not read.
2. Write what it says, in your own words, in a research note under `research/`, in a round folder or a new one, with section numbers and links. Quote at most one short passage.
3. Say which requirements it supports, contradicts or adds to.
4. For each, comment on the requirement's review issue, or propose a new requirement in its area page with status `Proposed`.
5. Run `just test` and open a pull request. The source register is regenerated from the reports when they change.
