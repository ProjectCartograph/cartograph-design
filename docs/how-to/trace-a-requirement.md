# Trace a requirement to its evidence

Find why a requirement exists and what supports it.

1. Find the requirement in [every requirement](../reference/requirements/README.md#every-requirement) and open it.
2. Read **Sources**. Each names a research report and the criterion in it (for example `g3 L2`).
3. Open the report and search for the criterion's identifier. Its row names the sources behind it, with section numbers.
4. To read a source, find it in [the sources](../reference/sources.md), and check the report's opening section for how far it was read.
5. To see which decisions rest on the requirement, search the [decision records](../reference/decision-log.md) for its identifier.
