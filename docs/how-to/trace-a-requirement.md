# Trace a requirement to its evidence

Find out why a requirement exists and what supports it.

1. Find the requirement in [every requirement](../reference/requirements/README.md#every-requirement) and open it.
2. Read **Why** for the reasoning and **Evidence** for its sources. Each cites a key in [the bibliography](../reference/bibliography.md), with a section where one applies.
3. In the bibliography, open the source and check **Read**: how far the source itself was read.
4. For the wider argument, read the part of [the evidence](../explanation/the-evidence.md) the source appears in.
5. To see which decisions rest on the requirement, search the [decision records](../reference/decision-log.md) for its identifier.
