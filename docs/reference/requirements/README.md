# Requirements

What Cartograph must do, as statements that can be checked. Each gives its reason, the conditions under which it is met, and the evidence for it in [the bibliography](../bibliography.md). Priorities follow MoSCoW: **Must** is needed for the first stable release, **Should** is wanted and may follow, **Could** is welcome. Every requirement starts **Proposed** and becomes **Approved**, **Changed** or **Dropped** in review ([how to review a requirement](../../how-to/review-a-requirement.md)).
