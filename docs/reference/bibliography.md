# Bibliography

Every source the design cites, by key. Requirements and decisions cite a key and, where it helps, a section: `[HMT-CASES] 4.14`.

**Read** says how far the source itself was read. *In full* and *in part* mean the source's own text; *summary* means only the publisher's public pages (a product page, a scope, a syllabus), because the text is sold or restricted. No requirement rests on a *summary* source alone.
