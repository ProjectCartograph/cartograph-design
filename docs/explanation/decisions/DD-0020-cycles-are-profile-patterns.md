# DD-0020 Cycles are patterns in the profile

**Status:** Accepted
**Date:** 2026-10-20
**Requirements:** [S3](../../reference/requirements/stages-and-cycles.md#s3-cycles-without-gates), [S8](../../reference/requirements/stages-and-cycles.md#s8-a-reference-cycle), [S9](../../reference/requirements/stages-and-cycles.md#s9-goals-hold-within-a-period-cycles-nest), [S10](../../reference/requirements/stages-and-cycles.md#s10-every-period-ends-in-a-decision), [X7](../../reference/requirements/domains-and-configuration.md#x7-reporting-periods-as-date-intervals), [R6](../../reference/requirements/shape-of-the-record.md#r6-one-place-for-each-concept)

## Context

Work without an end is steered by cycles whose events are shared across methods, governments and charities while their lengths differ ([S8](../../reference/requirements/stages-and-cycles.md#s8-a-reference-cycle); [SCRUM](../../reference/bibliography.md); [OKR](../../reference/bibliography.md); [ISO-HS](../../reference/bibliography.md); [GPRAMA](../../reference/bibliography.md); [CGC](../../reference/bibliography.md)). Each event already produces something Cartograph records: goals and targets, readings, reviews, lessons, evaluation findings and decisions ([DD-0007](DD-0007-decisions-stages-and-reviews-are-records.md)). Periods are already date intervals generated by the profile's calendar ([X7](../../reference/requirements/domains-and-configuration.md#x7-reporting-periods-as-date-intervals)).

## Options

| Option | For | Against |
|---|---|---|
| A. A cycle as a record with periods and event records of its own | Everything about a cycle in one place | Goals, reviews, lessons and decisions held twice, once on the cycle and once on the work ([R6](../../reference/requirements/shape-of-the-record.md#r6-one-place-for-each-concept)) |
| B. A cycle as a pattern in the profile; periods generated by its calendar; each event recorded with the record it already has | One place for each concept; profiles carry recognised cycles as they carry life cycles | A period must be named by each record made in it; a cycle has no single page of its own unless a view assembles one |
| C. No reference: a free calendar per workspace | Simplest | Cycles stop being comparable, and nothing asks for the decision at the close |

## Decision

Option B. A **cycle** is data in the profile: its events mapped to the reference cycle, its length mode, its calendar, its deciding role and any parent cycle ([DD-0008](DD-0008-profiles-hold-what-differs-between-domains.md)). A piece of work steered by cycles names its cycle; its **periods** are date intervals generated by the calendar as reporting periods are, though a period is not a reporting period ([X7](../../reference/requirements/domains-and-configuration.md#x7-reporting-periods-as-date-intervals)). Each event is recorded with an existing record, which names its period:

| Event | Recorded as |
|---|---|
| Set | Goals and targets for the period ([M3](../../reference/requirements/results-and-measures.md#m3-targets-over-time-and-what-achievement-means)); a decision where the profile separates who commits |
| Check | Readings; a review where the profile asks for one |
| Review | A review ([A5](../../reference/requirements/risk-and-assurance.md#a5-reviews-are-records-apart-from-approvals)) |
| Look back | Lessons |
| Evaluate | An evaluation plan and its findings ([E4](../../reference/requirements/change-and-evaluation.md#e4-decisions-the-evidence-must-inform) to [E7](../../reference/requirements/change-and-evaluation.md#e7-findings-change-decisions-and-lessons-are-found)) |
| Decide | A decision ([D5](../../reference/requirements/case-and-decisions.md#d5-a-decision-is-a-record)) |

A view assembles a period's records into one page, as views assemble everything else ([DD-0010](DD-0010-views-are-renderings.md)).

## Consequences

- No new record: cycles add profile data and a period on existing records.
- A decision at a period's close names the period and the version of the case it rests on.
- Profiles mark where they add an event their source does not name, such as the decide event for Scrum.
