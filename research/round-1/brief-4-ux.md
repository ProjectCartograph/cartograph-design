# Agent 4: tools, guided flows and usability testing

Read COMMON.md in this folder first, and Diátaxis.

Part A: **the landscape.** What do established tools and templates ask
when someone charters or initiates a project? Use primary vendor
documentation and official templates: Atlassian (Confluence project
poster and charter templates, Jira Product Discovery), Asana, monday.com,
Notion, Smartsheet, Microsoft Project / Planner, Miro project canvas,
and any open-source chartering or strategy-mapping tool you find. Note
how each guides a newcomer versus an expert.

Part B: **guided flows and cognitive load.** From trusted research:
GOV.UK Design System and Service Manual ("one thing per page", question
pages, check answers, task list pages), Nielsen Norman Group (wizards,
progressive disclosure, staged disclosure, onboarding, cognitive load,
Hick's law, power-user accelerators), Baymard or Caroline Jarrett on
forms, and academic work on cognitive load and novice versus expert
interfaces. Write design principles for Cartograph's walk-first redesign,
each with its source, covering: a new Home (a short choice of tasks,
pick up where you left off), task walks, the task list pattern, check
your answers before saving, how the full workspace stays one step away,
and accelerators for power users. Use the screen audit figures in
COMMON.md.

Part C: **the in-person test script** for ProjectCartograph/cartograph-ui#136,
following trusted usability testing practice (NN/g, GOV.UK service
manual on user research, Steve Krug's Rocket Surgery Made Easy where
you can source it, the Single Ease Question and SUS): three tasks
(define a project; review and merge a change set; record an indicator
reading), the facilitator's exact words, when they may help, what to
note (finished unaided, with help, given up, and where), the short
difficulty form, consent and what is recorded (the people's trace,
docs/EVALUATING_PEOPLE.md "Recording a test session"), and how many
participants of each kind. Write it as a Diátaxis how-to guide.

Outputs, under /home/cascadura/git/project-cartograph/.eval/research/:
tools-and-ux.md (parts A and B) and test-script.md (part C).
